# Luhn Algorithm Project

A Python implementation of the famous Luhn Algorithm used to validate credit and debit card numbers.

## Project Goals

* Understand checksum validation
* Practice Python programming
* Learn string processing techniques
* Build a real-world validation tool

## Skills Demonstrated

* Functions
* Loops
* String methods
* Algorithm implementation
* Problem solving

## Future Improvements

* User input support
* GUI interface
* Web version using HTML/CSS
* Batch card validation
